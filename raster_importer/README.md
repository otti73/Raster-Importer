# Raster Importer QGIS Plugin

Das **Raster Importer** Plugin für QGIS ermöglicht das schnelle und unkomplizierte Laden von Rasterdaten. 

## Hauptfunktionen:
- **Instant Canvas Fit:** Georeferenziert ungeoreferenzierte Bilder (JPG, PNG, TIF) automatisch über eine GDAL VRT-Datei direkt in den aktuell sichtbaren Kartenausschnitt.
- **QGIS Integration:** Nutze nativer QGIS-Dialoge und Benachrichtigungen.
